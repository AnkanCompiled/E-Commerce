# E-Commerce

A vercel deployed simple e-commerce website using next.js

[![Vercel](https://img.shields.io/badge/Live%20Demo-Vercel-black?logo=vercel)](https://e-commerce-kappa-self.vercel.app/)

---

## 🧰 Tech Stack

- Next.js
- TailwindCSS
- Vercel
- Supabase

---

## 🛠️ Installation

```bash
# Clone the repository
git clone https://github.com/AnkanCompiled/E-Commerce.git

# Go into the repo
cd E-Commerce

# Install dependencies
npm install

# Start development server
npm run dev
```
